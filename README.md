# Azure Security Engineering Lab

This project demonstrates building a cloud-native detection and response platform using Azure, Microsoft Sentinel, KQL, and automation.

## Goals
- Learn Azure security fundamentals
- Build detection engineering skills
- Implement automation workflows
- Simulate real-world attacks
